# NLP_proj_LLM_w-RAG

## How to run? 

Run python notebook first, then run the .py file. If it doesn't work, copy-paste the code from the python file inside a new cell at the end of the notebook. For the "config.ini" file, you might need to update the file location, especially for the "wiki-musiqueqa-corpus" and the "wikimultihopqa". Optionally, one might have to outcomment the line related to mounting the google drive if ran via colab.
